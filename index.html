Cloud Sync (Google Sheets)

Cloud sync is completely optional — the dashboard works fully offline using your device's local storage. Turn this on only if you want your mock data backed up and available across multiple devices (phone, laptop, etc.) via a Google Sheet.

Paste your Google Apps Script Web App URL below. Once connected, this dashboard will save and load data from the same Google Sheet on any device — phone, laptop, anywhere.

How to set it up with Google Sheets:

1. Create a new Google Sheet to store your mock data.

2. In the Sheet, go to Extensions → Apps Script and paste a small script that handles GET (read) and POST (write) requests, returning/saving JSON.

3. Deploy it as a Web App (Execute as: Me, Access: Anyone), then copy the generated URL.

4. Paste that URL below and hit "Save & Connect" — your data will sync automatically from then on.
